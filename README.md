# Rocket League Stats API App

This is a basic web app that connects to your Rocket League client via the [Stats API client](https://code.spirkop.com/samuel/rocket-league-stats-api-client) I've created previously. This is mostly to show what is possible with this API.

Everything happens locally on your device(s), I don't want and I won't get any of your data.

You can use the web app at https://rls.piku.spirkop.com.
